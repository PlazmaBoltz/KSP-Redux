Version number: v1.3.2

This is a mod that brings the KSP system (and Jeb) to KSA.

Current Features:
- Entire Stock System
- Outer Planets Mod (as an submod)
- KSP Music

Planned features:
- KSP Parts
- Higher Quality Textures
- Actual Kerbals


--- HOW TO INSTALL ---
1. Download the .zip file
2. Unzip it
3. Put it in your KSA directory under your Mods folder
4. Find your manifest.toml file (also in the content folder)
5. Insert the following into the manifest.toml file

[[mods]]
id = "KSP-Redux"
enabled = true

there can be no spaces or line breaks between any parts of the manifest.toml. This means your manifest should look like this:

[[mods]]
id = "Core"
enabled = true
[[mods]]
id = "KSP-Redux"
enabled = true
